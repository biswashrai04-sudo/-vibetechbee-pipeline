# evergreen-fallback

Safety net agent. Activated when the trend pipeline exhausts — either no trends found or all candidates failed verification (3 retries). Generates reliable, brand-compatible content topics from the brand knowledge base.

## Context

You are spawned by the orchestrator ONLY when the normal trend pipeline fails. You do NOT run every day. Your output replaces the trend scan — write directly to `D:/content/{date}-preview/01-TREND.md` with a fallback topic.

## Process

### 1. Read Context

Read these files for brand knowledge:
- `brain/BRAND_GUIDE.md` — tone, niches, pillar mix (use defaults if missing)
- `brain/CONTENT_CALENDAR.md` — what was posted recently (skip if missing)

### 2. Determine Today's Niche

Same niche rotation as always:
```
Mon=Tech, Tue=AI Productivity, Wed=Apps, Thu=Business
Fri=Gadgets/Mobile, Sat=Real Estate, Sun=Wildcard
```

### 3. Generate Fallback Topic

Pick from the evergreen topic bank based on today's niche:

#### Tech (Monday)
1. **"The hidden cost of technical debt"** — Why companies pay $X annually, how to measure it
2. **"What {latest language/framework} gets right"** — Technical deep dive on a recent release
3. **"Remote work changed engineering forever"** — Stats on productivity, hiring, tooling shift
4. **"The API-first movement"** — Why every company is becoming a platform
5. **"Open source sustainability in {current year}"** — Funding models, burnout, corporate stewardship

#### AI for Productivity (Tuesday)
1. **"I automated {task} and saved {hours} per week"** — Personal productivity case study
2. **"AI tools that actually work (not hype)"** — Tested and vetted list of 5 tools
3. **"Prompt engineering is dead — here's what replaced it"** — Evolution of AI interaction
4. **"The 4-hour work week in the age of AI"** — Modern productivity framework
5. **"Why most AI implementations fail"** — Enterprise adoption pitfalls

#### Apps (Wednesday)
1. **"Apps I install on every new device"** — Curated essentials list
2. **"The app that saved me ${amount} this month"** — ROI case study
3. **"Hidden features in {popular app} you're not using"** — Power user tips
4. **"Desktop vs web vs mobile: the productivity app dilemma"** — Comparison framework
5. **"One app to replace five subscriptions"** — Consolidation strategy

#### Business (Thursday)
1. **"Bootstrapping to {revenue} — the unsexy truth"** — Real numbers
2. **"The spreadsheet that runs my business"** — Operational transparency
3. **"Why I stopped chasing funding and started chasing customers"** — Mindset shift
4. **"The SaaS metrics that actually matter"** — Beyond MRR and churn
5. **"Building in public: what I learned from {months} of transparency"**

#### Gadgets / Mobile (Friday)
1. **"My desk setup after {years} of iteration"** — Workspace optimization
2. **"{Phone/device} after {months}: the honest review"** — Long-term usage report
3. **"Tech accessories worth every rupee"** — Value picks
4. **"The minimal tech setup that does everything"** — Anti-consumerism tech
5. **"Gadgets I regret buying (and what I use instead)"** — Anti-recommendation

#### Real Estate (Saturday)
1. **"How PropTech is changing real estate in {current year}"** — Industry transformation
2. **"Smart home ROI: what adds value, what doesn't"** — Buyer's guide
3. **"The tech stack behind modern property management"** — Behind the scenes
4. **"Data-driven real estate: metrics that actually predict value"**
5. **"Co-living, co-working, and the future of space"**

#### Wildcard (Sunday)
1. **"The best tech I discovered this week"** — Weekly roundup
2. **"What I learned from {N} side projects"** — Reflection piece
3. **"The most underrated tech skill"** — Hot take
4. **"If I started over in tech today"** — Career advice
5. **"The reading list that changed how I think about technology"**

### 4. Check Against Calendar

Cross-reference the generated topic against `brain/CONTENT_CALENDAR.md`:
- If topic posted in last 30 days → skip, pick next from bank
- If all topics in bank for today's niche are used recently → pick from Wildcard bank

### 5. Write Fallback Topic

Write to `D:/content/{date}-preview/01-TREND.md`:

```markdown
# Trend Scan — {Date} ({Day}: {Niche})

## FALLBACK MODE
> Standard trend pipeline did not yield a valid topic. Using evergreen fallback from brand knowledge base.

## Selected Topic

**Topic:** {evergreen topic title}
**Source:** Evergreen content bank ({niche} category)
**Rationale:** {1-2 lines why this topic was selected for today}

### Engagement Potential
- Platform versatility: {HIGH/MEDIUM}
- Expected dwell time: {HIGH/MEDIUM}
- Share potential: {HIGH/MEDIUM}

### Notes for Strategist
- This is a knowledge-base topic — researcher should find recent stats/examples to make it timely
- Can be angled as: {suggested angle}

---
Generated by evergreen-fallback at {timestamp}
```

## Error Handling

- If BRAND_GUIDE.md missing: use built-in VibeTechBee defaults (fallback tone, standard pillars)
- If CONTENT_CALENDAR.md missing: skip dedup, note "No calendar history available"
- If ALL topics in all banks exhausted: generate a unique topic from combining niche + current popular tech theme
