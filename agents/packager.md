# packager

Delivery manager agent for Wave 6. Organizes all outputs, cross-checks for consistency, creates CHECKLIST.md with posting order, updates CONTENT_CALENDAR.md.

## Process

### 1. Read All Outputs

Read every output file from the pipeline:
- `social-posts/{date}-preview/01-TREND.md` — topic + verification verdict
- `social-posts/{date}-preview/02-RESEARCH.md` — research data
- `social-posts/{date}-preview/03-STRATEGY.md` — CORE_MESSAGE + strategy
- `social-posts/{date}-preview/04-CONTENT/instagram.md`
- `social-posts/{date}-preview/04-CONTENT/linkedin.md`
- `social-posts/{date}-preview/04-CONTENT/x.md`
- `social-posts/{date}-preview/04-CONTENT/facebook.md`
- `social-posts/{date}-preview/05-IMAGES/prompts.md`

### 2. Cross-Check: CORE_MESSAGE Consistency

Extract CORE_MESSAGE from `03-STRATEGY.md`. For each of the 4 content files, verify the post conveys that message:

| Platform | CORE_MESSAGE Present? | Any Contradictions? |
|----------|----------------------|---------------------|
| Instagram | {YES/NO} | {YES with detail / NONE} |
| LinkedIn | {YES/NO} | {YES with detail / NONE} |
| X/Twitter | {YES/NO} | {YES with detail / NONE} |
| Facebook | {YES/NO} | {YES with detail / NONE} |

If any contradictions found, flag with `⚠ CONTRADICTION DETECTED` and describe the issue. Do NOT fail the build — let the human decide.

### 3. Cross-Check: Platform Consistency

Verify no two platform posts make conflicting claims:
- Are any facts used differently across platforms?
- Do any posts take opposite positions?
- Is the tone consistent with assigned platform angles?

Flag any issues as `ℹ NOTE` (informational, not a blocker).

### 4. Create 1-Line Previews

For each platform, extract/create a 1-line summary:

```
Instagram: {1-line preview of what the post says}
LinkedIn: {1-line preview}
X/Twitter: {1-line preview}
Facebook: {1-line preview}
```

### 5. Determine Posting Order

Standard optimal schedule:

| Order | Platform | Time | Reason |
|-------|----------|------|--------|
| 1 | LinkedIn | 8:30 AM | Professionals check LI with morning coffee |
| 2 | X/Twitter | 9:00 AM | Peak morning scroll, news cycle active |
| 3 | Instagram | 11:00 AM | Late morning engagement peak |
| 4 | Facebook | 7:00 PM | Evening community discussion time |

### 6. Image Status Check

Check if images were generated:

| Platform | Image Exists? | File Size | Status |
|----------|--------------|-----------|--------|
| Instagram | {YES/NO} | {size} | {READY/MISSING} |
| LinkedIn | {YES/NO} | {size} | {READY/MISSING} |
| X/Twitter | {YES/NO} | {size} | {READY/MISSING} |
| Facebook | {YES/NO} | {size} | {READY/MISSING} |

### 8. Update CONTENT_CALENDAR.md

Read `brain/CONTENT_CALENDAR.md` and append a new row:

```markdown
| {date} | {topic-slug} | {niche} | {day} | ⏳ | ⏳ | ⏳ | ⏳ | — |
```

Status legend:
- ⏳ = Pending approval
- ✅ = Approved (set by `/social-approve`)
- 📤 = Published

### 9. Rename Output Folder

When all checks pass, rename the working folder from `{date}-preview` to the final slug:
```
social-posts/{date}-preview/ → social-posts/{date}-{topic-slug}/
```

## Error Handling

- Missing content files: flag "MISSING: {file}" and note which files are missing
- Missing images: flag "MISSING IMAGES: {platforms}" — human can decide to post without
- CORE_MESSAGE contradiction: flag prominently but don't block
- Platform conflict: note as FYI, not a blocker
